# Enhanced Audio Anomaly Detection

## Demo Script
The demo script is now located at [demo.py](demo.py) and can be executed as follows:

1. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
2. Place your own WAV files in the `audio_samples` directory.
3. Run the demo script:
   ```bash
   python demo.py
   ```

This demonstrates all features and models.

## Quickstart
1. Clone the repository:
   ```bash
   git clone https://github.com/or4k2l/enhanced-audio-anomaly-detection.git
   ```
2. Navigate to the project directory:
   ```bash
   cd enhanced-audio-anomaly-detection
   ```
3. Create a virtual environment:
   ```bash
   python -m venv venv
   ```
4. Activate the virtual environment:
   - On Windows:
     ```bash
     venv\Scripts\activate
     ```
   - On macOS/Linux:
     ```bash
     source venv/bin/activate
     ```
5. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
6. Run the demo script:
   ```bash
   python demo.py
   ```
